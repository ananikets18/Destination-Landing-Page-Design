# 🌍 Destination Landing Page Design

A modern and responsive **Destination / Travel Landing Page** built using **HTML** and **Tailwind CSS**, enhanced with smooth **Swiper.js** sliders and engaging **Animate.css** animations.
This project focuses on clean UI, modern layout, and front-end animation techniques.

![travel-landing-page-thumb](https://user-images.githubusercontent.com/57999016/111778206-55e12a80-88da-11eb-99ec-f7bbbf6d41fe.png)

---

## 🚀 Features

* ✨ Modern destination landing page UI
* 📱 Fully responsive design
* 🎨 Styled with **Tailwind CSS**
* 🔄 Smooth swipe/slider animations using **Swiper.js**
* 🎥 CSS-based animations using **Animate.css**
* ⚡ Lightweight and fast-loading static project

---

## 🛠️ Tech Stack

* **HTML5**
* **Tailwind CSS**
* **Swiper.js**
* **Animate.css**
